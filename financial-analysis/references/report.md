# Фирменный финансовый отчёт

Генератор использует одностраничную форму ВБетон 0.8. Шапка содержит логотип и круговой рейтинг из предоставленного кредитного отчёта. Лист отчётности содержит до трёх сопоставимых периодов, график поступлений и погашений, структуру долга и сравнение до и после нового займа. Лист покрытия содержит шестимесячный расчёт и исторические показатели. Для ИП без бухгалтерской отчётности он показывает денежные потоки вместо бухгалтерской таблицы.

## Вход

Входной файл UTF-8 JSON содержит `schema_version: 1`, `report_id`, `subject`, `borrower_id`, дату `as_of` в ISO и трёхбуквенную `currency`. Поле `demo: true` помечает учебный PDF. Укажи `accounting_mode: corporate` для бизнеса с бухгалтерской отчётностью или `ip` для ИП без неё. Форма использует русские подписи.

Факт выглядит как `{"status":"confirmed","value":12000,"sources":["S1"]}`. Для расчётного значения укажи `status: calculated` и `derivation`. Отсутствующий факт можно оставить как `null`. Конфликтующие и неподтверждённые значения оставляют поле в PDF пустым. Подтверждай единицы, принадлежность, даты и исходные значения в документах. Досье источников сохраняй вместе с JSON. Используй безопасные названия документов и нужные страницы или строки.

`financial.fields` принимает `summary`, `amount`, `rate`, `term`, `chart_period`, `debt_date`, `ratio_period` и `footnote`. Помести существенный вывод и ограничения в доступное место формы. Сумма займа передаётся числом в валюте отчёта. Остальные условия имеют исходные единицы или текст.

`financial.periods` и `financial.balance_dates` содержат по три факта. Заполни `financial.statements` отдельными массивами фактов той же длины. Массивы выручки, прибыли от продаж и чистой прибыли идут в порядке периодов, активы и обязательства соответствуют датам баланса. Денежные факты передаются в основных единицах валюты, пересчёт в миллионы делает шаблон. Ключи `statements` перечислены в `STATEMENTS` файла `scripts/financial_layout.py`.

Для графика заполни `financial.cashflow` с ключами `revenue`, `net_credit_turnover`, `principal_paid`, `cash_interest_paid`. Для действующего долга заполни `financial.current_debt.bank_principal`, `unrelated_nonbank_principal`, `related_party_principal`. Для соотношений укажи `financial.ratios.interest_coverage` и `debt_equity`, каждое со значениями `before` и `after`. Основания для соотношений могут отличаться по датам, поэтому укажи `ratio_period` и `debt_date`.

## Рейтинг кредитного бюро

Добавь источник и карточку субъекта. Для заёмщика `persons[].id` совпадает с `borrower_id`, а `persons[].name` с `subject`.

```json
{
  "sources": [
    {
      "id": "BKI",
      "title": "Кредитный отчёт",
      "locator": "Страница 1, индивидуальный рейтинг",
      "document_date": "2025-12-28",
      "credit_report": {"bureau": "Учебное бюро", "person_id": "DEMO-01"}
    }
  ],
  "persons": [
    {
      "id": "DEMO-01",
      "name": "Учебная компания",
      "score_max": 999,
      "score": {"value": 742, "status": "confirmed", "as_of": "2025-12-28", "sources": ["BKI"]}
    }
  ]
}
```

Укажи фактическую исходную шкалу бюро. Сверь имя и идентификатор лица, дату, само число и шкалу. Рейтинг должен однозначно относиться к тому же лицу и дате. Собственный расчёт, спорное значение или ссылка на отчёт другого лица не создают круг. Форма в первую очередь показывает рейтинг заёмщика. При его отсутствии используется подтверждённый рейтинг другого участника с именем. В форме покрытия остальные подтверждённые рейтинги помещаются ниже. При необходимости `sources[].url` может содержать согласованную HTTPS-ссылку на кредитный отчёт, доступную получателю PDF.

## Выбор листа

Для графика и сравнения по отчётности укажи `layout: statement`. Для расчётных карточек укажи `layout: coverage` и передай результат `analyze_cash_position.py` через `--cash-position`. По умолчанию для корпоративной отчётности без такого результата используется `statement`. С расчётом денежной позиции или для ИП используется `coverage`.

```sh
python "$SKILL_DIR/scripts/render_report.py" report.json financial-report.pdf
python "$SKILL_DIR/scripts/render_report.py" ip-report.json financial-ip-report.pdf --cash-position cash-position-result.json
```

Сверь дату, валюту, заёмщика и формулировки. График строится при подтверждённых или расчётных значениях по всем четырём строкам. Сохраняй объяснение пропусков в отчётном JSON и вынеси существенные пробелы в сам PDF. При переполнении страницы сокращай подписи и оставляй подробности в рабочем файле. После рендера визуально проверь таблицы, логотип, круг рейтинга и соответствие чисел исходным материалам.
